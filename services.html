Services

What we do, and what each engagement typically includes. Scope is always confirmed with you before work starts.

IT infrastructure

We design office and site infrastructure so it is sized for today and can grow without a rebuild. That covers hardware selection, cabling plans, power and backup considerations, and clear documentation.

Ask about this service
  • Infrastructure assessment and design
  • Hardware and software selection
  • Installation and handover documentation

Server administration

We administer Windows and Linux servers: setup, user and permission management, patching, monitoring and backups, so problems are caught early and restores are tested.

Ask about this service
  • Setup and hardening
  • Patching, monitoring and backups
  • Restore testing and recovery planning

Networking

From a single office to multiple branches, we plan and configure routers, switches, firewalls, VLANs, Wi-Fi and VPN links, and keep addressing and settings documented.

Ask about this service
  • LAN, Wi-Fi and VPN configuration
  • Firewall and access policies
  • Troubleshooting and performance review

Managed IT support

Ongoing support for users and systems under an agreed scope: help requests, maintenance, updates and proactive checks. Scope and response expectations are agreed in writing before work starts.

Ask about this service
  • Helpdesk and on-site or remote support
  • Routine maintenance and checks
  • Agreed scope and reporting

Business systems

We help select, install and configure business applications such as accounting, inventory, document and workflow tools, and connect them to your existing environment.

Ask about this service
  • Requirements review
  • Installation and configuration
  • User onboarding and data migration support

POS systems

We set up POS software with the hardware around it: receipt printers, barcode scanners, cash drawers and tablets or terminals, plus the network and backups that keep sales running.

Ask about this service
  • POS software and hardware setup
  • Product, price and user configuration
  • Training and support

Open-source solutions

We deploy and maintain open-source software for servers, collaboration, monitoring and more. We recommend it when it suits your needs and tell you plainly when it does not.

Ask about this service
  • Evaluation against your requirements
  • Deployment, hardening and updates
  • Documentation and handover

Virtualization

We consolidate workloads onto virtualized hosts, set up virtual machines and templates, and plan snapshots and backups so systems are easier to move, test and restore.

Ask about this service
  • Host and VM design
  • Migration of existing servers
  • Snapshot and backup strategy

Docker and containers

We package and run applications in containers with Docker and Compose, so environments are consistent, updates are controlled and rollbacks are simpler.

Ask about this service
  • Containerizing applications
  • Docker Compose stacks
  • Updates, volumes and backups

Cloud

We help businesses move suitable workloads to the cloud, set up cloud storage, email and hosted servers, and connect them securely with on-site systems.

Ask about this service
  • Cloud readiness review
  • Setup and migration
  • Access control and cost awareness

IT asset management

We build an inventory of hardware, software and licences, with ownership, location and lifecycle details, so purchasing, audits and replacements are planned, not improvised.

Ask about this service
  • Asset inventory and tagging approach
  • Licence and warranty tracking
  • Lifecycle and replacement planning

Automation

We automate recurring tasks such as backups, reports, user setup, monitoring alerts and data transfers using scripts and open tools, with logs so you can see what ran.

Ask about this service
  • Task and workflow review
  • Scripts and scheduled jobs
  • Logging, alerts and documentation
